# 情绪与情感

情绪与情感能够产生能量——并且在觉醒者的增幅下能够有相当的破坏力。
标准计量单位为EW（EmoWatt）。当然，因为觉醒带来的巨大增幅，同时设置了KEW（KiloEmoWatt）以测量。（1000 EW = 1 KEW）

大多数情况下，正常人类所能触及到的极限是 0.8 EW。当情绪强度到达 1.05 EW 且精神未崩溃，则会「觉醒」。觉醒后的常态化将被拉伸至 0.235 KEW。
多个人的情绪/情感产生的能量能够叠加（类型越接近，合成后的能量保存度更高）。
「复觉醒」要求情绪强度达到 1.44 KEW 且精神未崩溃。每触发一次复觉醒，下一次复觉醒的精神强度将在上一次的基础上增加 1.44 KEW 且精神未崩溃。（详见：复觉醒）
