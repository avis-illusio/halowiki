# 时间历法：新元

以新世界创建的当日的公历零点为新元起点(新历1年1月1日 0时0分0秒，或写作00:00:00, 1 January 1 NE)。

## 年与日
新世界所在行星的绕日轨道较旧世界地球更外扩，公转周期随之延长；在新世界标准时间中，一年恰为440个标准日。每日仍沿用旧制：24小时、60分、60秒。因年长为整数日，新元历无闰年、无闰日、无闰秒。

## 四季与十二月
为使历法与季节相合，一年分十二月，四季各三月；每季恰为110日，全年合计440日。月长依次如下：
